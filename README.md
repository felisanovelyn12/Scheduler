# Scheduler

## What
A scheduling assistant that automatically organizes, adjusts, and optimizes user's calendar based on priorities, deadlines, and availability.

## Features

- Automatically creates and adjust schedules based on priorities, deadlines, and user availability
- Reorganizes scheduled event when new events are added
- Suggests alternative time when there is event conflict
- Alert user about upcoming deadlines
- Identifies free time during the day

## Who

- Students managing coursework and deadlines
- Professionals balancing meetings, tasks, and projects
- Anyone who wants automated time management 

## Why

- To help users maintain work life balance
- To prevent missed deadlines and time conflicts

## User Stories

- As a user, I want to be able to automatically organize my tasks
- As a user, I want to be warned when two events conflict
- As a user, I want my deadlines to be automatically prioritized
- As a user, I want to see my free time
